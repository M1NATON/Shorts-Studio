# Shorts Studio

Локальная студия, которая делает информационные ролики на английском из одной темы: сценарий, озвучка, анимированная графика, субтитры и готовый MP4. Два формата — YouTube Shorts 9:16 и длинные ролики 16:9.

Модель не пишет код анимации. Она заполняет типизированный JSON по готовым сценам (хук, счётчик, график, сравнение, хронология, список, цитата, композиция из блоков). Каждую сцену рисует проверенный Remotion-компонент, поэтому рендер предсказуем, а озвучка, субтитры и анимация совпадают по кадрам.

## Что умеет

- **Тема → готовый ролик.** Поиск фактов (Firecrawl), план тезисов, кадры по сценам, озвучка (Fish Audio) с пословными таймингами, фото и видео на фон (Pexels), музыка, MP4.
- **Очередь.** Несколько тем сразу, по строке на тему. Разные ролики собираются параллельно. Идущую задачу можно остановить.
- **Редактор.** Плеер, таймлайн сцен, правка текста и кадра, пересборка одной сцены (визуал, текст или озвучка) без трогания остальных, варианты сцены, safe-зона интерфейса Shorts.
- **Публикация.** Название, описание, хэштеги и промпт для генератора обложки.
- **Сохранение в папку.** Каждый ролик кладётся в свою подпапку вместе с `описание.txt`.

## Требования

- Node.js 22 или новее и pnpm 11 (`corepack enable`)
- ffmpeg и ffprobe в `PATH`: обработка озвучки и замеры громкости
- Ключи провайдеров:
  - модель — любой OpenAI-совместимый endpoint
  - Fish Audio — озвучка
  - Firecrawl — поиск фактов, необязательно
  - Pexels — фото и видео, необязательно

Видеокарта не обязательна. По умолчанию рендер рисует кадры через Vulkan и кодирует видео аппаратно, если это доступно. Если без видеокарты рендер падает, задайте `RENDER_GL=off` (см. «Переменные окружения»).

## Установка и запуск

```bash
pnpm install
cp .env.example .env   # необязательно: ключи можно задать в интерфейсе
pnpm studio
```

Студия откроется на http://127.0.0.1:3100 (API — на порту 3001). При первом запуске `pnpm studio` сам соберёт проект. После обновления кода пересоберите:

```bash
pnpm studio --build
```

Студия слушает только `127.0.0.1`: авторизации нет, а через API можно удалять проекты и менять ключи. Не открывайте её в сеть.

## Настройка

**Настройки → Провайдеры.** Base URL, модель и ключ модели, голос Fish Audio (reference id) с кнопкой «Прослушать», ключи Firecrawl и Pexels. Кнопка «Проверить» делает пробный запрос. Значения из интерфейса важнее `.env`.

Ключи хранятся только на сервере, в базе `storage/studio.sqlite`. В браузер приходит маска `••••1234`.

У модели есть два полезных поля:
- **Одновременных запросов** — по умолчанию 2. Если прокси модели отвечает 504 или пустыми ответами, уменьшите.
- **Быстрая модель для кадров** — можно указать модель быстрее и дешевле основной, она будет заполнять кадры сцен.

**Настройки → Экспорт.** Абсолютный путь к папке для готовых роликов, например `/home/ars/Видео/YouTube`.

**Музыка.** Положите mp3/ogg/wav/m4a в `storage/music/`. Префикс в имени файла задаёт настроение: `calm-`, `upbeat-`, `tech-`, `dramatic-`, `playful-`, `serious-`. По нему трек подбирается к ролику, например `dramatic-the-hope.mp3`.

## Как пользоваться

1. На главной введите тему (или несколько — по строке на тему). Выберите формат 9:16 или 16:9, режим фактов (авто, свежие или вечные), поиск и стиль субтитров. Нажмите «Создать ролик».
2. Ролик встаёт в очередь. Прогресс видно на карточке и в ящике очереди. Остановить можно там же или в меню карточки.
3. Откройте ролик. Проверьте сцены в плеере и по таймлайну, поправьте текст или кадр, при необходимости пересоберите отдельные сцены.
4. Нажмите «Экспорт MP4», затем «Скачать MP4» или «Сохранить в папку». Во втором случае в папке экспорта появится `<Название>/<Название>.mp4` и `описание.txt`. Повторный экспорт обновит ту же папку, а ролик с тем же названием получит соседнюю — `<Название> 2`.
5. В панели «Публикация» — название, описание и хэштеги для YouTube и промпт для обложки: вставьте его в Midjourney, Nano Banana и т.п.
6. «Экспорт → Скопировать для проверки» выгружает сценарий в Markdown, чтобы проверить факты сторонней нейросетью.

## Команды

| Команда | Что делает |
|---|---|
| `pnpm studio` | Студия целиком: API с очередью и веб на одном URL |
| `pnpm build` / `pnpm typecheck` / `pnpm test` | Сборка, проверка типов, тесты всех пакетов (turbo) |
| `pnpm lint` | ESLint |
| `pnpm e2e` | Сквозные тесты Playwright на фальшивых провайдерах. Рендерят настоящий MP4 |
| `pnpm check:secrets` | Ищет значения ключей из `.env` в собранных артефактах (после `pnpm build`) |
| `pnpm remotion:studio` | Remotion Studio для работы над сценами (порт 3210) |

Скрипты без интерфейса. Ключи берут из настроек студии или `.env`:

| Скрипт | Назначение |
|---|---|
| `node scripts/make-video.mjs "Тема" [--format=shorts\|landscape] [--minutes=3] [--freshness=current\|evergreen]` | Ролик от темы до MP4 в `storage/` |
| `node scripts/import-manifest.mjs [storage/manifest.json] [--topic="Тема"]` | Импорт ролика, собранного CLI, в библиотеку студии |
| `node scripts/regen-scene.mjs <номер> ["пожелание"] [--variants=2]` | Варианты визуала одной сцены манифеста |
| `node scripts/render-manifest.mjs [out.mp4]` | Рендер готового `storage/manifest.json` без генерации |
| `node scripts/render-stills.mjs [manifest.json] [outDir]` | PNG-кадры каждой сцены — быстрая проверка визуала |
| `node scripts/normalize-audio.mjs [--storage=storage]` | Выровнять громкость уже готовой озвучки. Перед этим делает резервную копию |

## Переменные окружения

Все необязательны.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | — | Модель, если не задана в интерфейсе |
| `FISH_API_KEY`, `FISH_MODEL`, `FISH_REFERENCE_ID` | — | Озвучка |
| `FIRECRAWL_API_KEY` | — | Поиск фактов |
| `PEXELS_API_KEY` | — | Фото и видео |
| `WEB_PORT` / `PORT` | `3100` / `3001` | Порты веба и API |
| `STORAGE_DIR`, `DB_FILE` | `storage`, `studio.sqlite` | Где лежат база, проекты и рендеры |
| `TTS_TEMPO` | `1.1` | Ускорение речи, `1` — без ускорения |
| `RENDER_HW` | — | `off` — без аппаратного кодирования |
| `RENDER_GL` | `vulkan` | Рендерер Chromium: `off`, `angle`, `egl` и т.п. |
| `RENDER_CONCURRENCY` | авто | Сколько кадров рендерить параллельно |
| `CHROME_BIN` | — | Путь к Chrome для `pnpm e2e`, если браузеры Playwright не скачаны |

## Устройство

pnpm-монорепозиторий на turbo, TypeScript.

```
apps/
  server/        Fastify API, очередь задач и пайплайн (генерация, озвучка, медиа, рендер)
  web/           Next.js: библиотека роликов, редактор, настройки
packages/
  contracts/     zod-схемы: сцены, манифест, форматы, данные публикации
  db/            SQLite (node:sqlite + drizzle): проекты, сцены, версии, задачи, настройки
  llm-core/      Генерация: исследование, план, раскладка, кадры, публикация, пересборка сцен
  media-core/    Fish Audio, пословные тайминги, числа словами, обработка звука, Pexels, таймлайн
  remotion/      Композиции Remotion: сцены, субтитры, фон, музыка; рендер MP4 и кадров
scripts/         CLI-скрипты и запуск студии
storage/         База, проекты, озвучка, рендеры, музыка (в git не попадает)
```

Путь ролика: тема → факты → план тезисов → раскладка по типам сцен (кодом) → кадр каждой сцены (модель, с проверкой схемой и починкой ответа) → озвучка по сценам с таймингами слов → фон из Pexels → манифест (кадр начала каждой сцены — источник истины) → превью в Remotion Player → рендер MP4.

Подробный план и решения — в [Plan.md](Plan.md) и [docs/](docs/).

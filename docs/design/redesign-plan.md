# Редизайн веба: направление A «Монтажная» + светлая тема

Статус: реализовано (фазы 0–6 одним коммитом — промежуточные состояния не собирались бы:
шапка переехала из layout в страницы). Сверх плана — анимация сборки ролика
(`GenerationProgress`: на обложке в библиотеке и крупно на сцене редактора).
Отложено: контекстное меню клипа (действия — в шапке инспектора), варианты ИИ остались
живыми плеерами, а не `<Thumbnail>` — движение кадра при выборе важнее.
Макеты: `docs/design/mockups/a-editor.html`, `a-library.html` (статичные, 1440×900; папка не в git, 20 МБ).
Скилл: `~/.claude/skills/app-ui-ux-best-practices` — перед приёмкой прогнать `references/design-audit.md`.

## Решения

- **Характер:** рабочий инструмент монтажёра. Интерфейс нейтральный, цвет — у роликов.
  Плотность высокая, углы 4 px, плоско (тени только у всплывающих слоёв), переходы 120 мс ease-out.
- **Шрифты:** IBM Plex Sans (интерфейс) и IBM Plex Mono (таймкоды, длительности, числа).
  Локально через `@fontsource/ibm-plex-sans` и `@fontsource/ibm-plex-mono` (кириллица есть),
  без запросов к Google в рантайме. Версии — выдержанные (`minimumReleaseAge`, исключения не добавлять).
- **Иконки:** `lucide-react` той же версии, что в `@shorts/remotion` (1.46.0), обводка 1.75, 16 px.
  Все символы-иконки (`⏳ ☾ ◐ ☀ ↑ ↓ ✓ ▾ ×`) заменить.
- **Темы:** тёмная и светлая, переключатель «система / светлая / тёмная» (как сейчас, `data-theme`).
  Сцена с плеером и таймлайн-кадры остаются тёмными в обеих темах: ролики тёмные, светлая рамка вокруг
  тёмного кадра читается хуже.

## Фазы (коммит после каждой)

### 0. Основа
- `globals.css`: токены выше, типографика (13 px база, 12 px подписи, mono для чисел), примитивы:
  `.btn` (+ `.pri`, `.ghost`, `.icon`), `.field`, `.select`, `.input`, `.tabs`, `.seg`, `.pill`,
  `.status` (точка + слово), `.menu` (выпадающее), фокус-кольцо `:focus-visible`.
- Зависимости: `lucide-react`, `@fontsource/ibm-plex-sans`, `@fontsource/ibm-plex-mono` в `apps/web`.
- `ThemeToggle` на иконках Sun / Moon / Monitor.
- `lib/labels.ts`: человеческие названия всего, что сейчас видно как код —
  типы кадра, `layout`, `motion`, `backdrop`, блоки (`pair` → «Пара»), поля (`at` → «Когда появится»,
  `emphasis` → «Выделить»), intent сцены. Одна таблица на весь UI.

### 1. Оболочка
- Шапка 48 px: знак (красная точка) + «Studio», хлебные крошки (Библиотека / название ролика),
  справа слот действий страницы. Навигация «Настройки» — иконкой-ссылкой справа.
- Редактор — во всю высоту окна без прокрутки страницы (прокручиваются только панели).

### 2. Библиотека (`app/page.tsx`, `CreateForm`, `ProjectTile`, `CaptionPicker`)
- Форма создания в одну строку: поле темы (растёт по строкам) + формат + факты + поиск + субтитры
  (кнопка открывает всплывающее окно с живыми образцами `CaptionPicker`) + «Создать ролик».
- Фильтры: поиск, статус, формат, счётчик.
- При фильтре «Все» — два ряда с заголовками «Shorts 9:16» и «16:9» (ровная сетка в каждом).
- Карточка: постер без наложенных бейджей; под ним название (обрезка в 2 строки),
  строка `● статус · 0:35 · дата`. Действия («Ещё версия», «Удалить» с подтверждением) — в меню `⋯`
  по наведению/фокусу, не на виду.
- Прогресс генерации — полоска и этап на постере вместо обложки.
- Пустое состояние: что делает студия + куда вводить тему. Баннер «настройте модель» — в стиле `.warn`.

### 3. Редактор (`app/video/[id]/page.tsx`, `VideoPlayer`, новые `Timeline`, `Transport`)
- Сетка: шапка / [сцена с плеером | инспектор 360 px] / таймлайн ~210 px.
- Шапка: крошки, `pill` «9:16 · черновик», «Субтитры: караоке» (всплывающее окно с образцами),
  «Safe-зона» (переключатель), главная кнопка «Экспорт MP4» → после рендера «Скачать MP4»;
  статус «устарел» — `--warn` рядом с кнопкой. Прогресс задач — тонкая полоса под шапкой + текст этапа.
- Плеер без встроенных контролов Remotion; свой транспорт под кадром: предыдущая сцена,
  play/pause, следующая, таймкод mono `0:16.4 / 0:35` (через `PlayerRef` и событие `frameupdate`).
- Таймлайн: линейка времени; клипы сцен шириной ∝ длительности, в клипе — кадр сцены через
  `<Thumbnail>` из `@remotion/player` (живой кадр из манифеста, без рендера на сервере),
  номер и длительность mono; выбранная — рамка `--accent`; плейхед `--accent` синхронизирован с плеером.
  Под клипами — строка с текстом озвучки (обрезка). Клик по клипу — выбрать сцену и перемотать.
  Главы 16:9 — метки над линейкой. Много сцен — горизонтальная прокрутка, минимальная ширина клипа 64 px.
- Действия сцены (← →, дублировать, добавить после, удалить) — иконки в шапке инспектора
  и контекстное меню клипа; из списка сцен убрать.
- Клавиши: пробел — play/pause, ←/→ — сцена, Alt+←/→ — переставить сцену.
- Источники ролика — выпадающее окно из шапки (сейчас внизу списка сцен).

### 4. Инспектор (`SceneInspector`, `BlockEditor`)
- Шапка: «Сцена 4», intent и длительность, иконки действий.
- Вкладки Кадр / Текст / ИИ / История (подчёркивание `--accent`).
- Кадр: общие поля с русскими подписями; короткие перечисления (раскладка, появление) — сегментами,
  длинные — select. Блоки — карточки: иконка + название + «когда появится» (mono), поля в сетку,
  убрать/переставить иконками. Живая валидация — строкой `--warn` под блоком.
- Нет в источниках — плашка `--warn` с числом.
- ИИ: поле пожелания + число вариантов; варианты — сетка `<Thumbnail>` с подписью, клик = выбрать.
- История: список версий с источником (вручную / ИИ / вариант), временем и кнопкой «Вернуть».

### 5. Настройки (`app/settings/page.tsx`)
- Одна колонка 720 px, три секции без карточек-коробок: заголовок + `status` («из .env / задано здесь /
  не задано»), поля, кнопки «Сохранить», «Проверить», у озвучки «Прослушать».

### 6. Приёмка
- Скриншоты всех экранов в обеих темах (Playwright, как при аудите) и сравнение с макетом A.
- `design-audit.md` из скилла; контраст; фокус с клавиатуры по всем контролам; `aria-label` у иконок.
- e2e: селекторы, на которые он опирается (`.scene-select`, `.block-card`, `.variant`, `.version`,
  `.issues`, `.jobs-bar`, `.player-wrap`, `aside .badge`, `input.input`), либо сохранить,
  либо перевести спек на роли и подписи (`getByRole`) — второе предпочтительнее.
- `pnpm build`, `pnpm test`, `pnpm e2e` (CHROME_BIN — пока Playwright-браузер не скачан), `check:secrets`.
